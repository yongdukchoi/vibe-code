# mock-board 기획서

## 1. 개요
- 로그인 후 게시판과 회원정보를 관리하는 React 앱.
- 서버가 아직 없으므로 **모든 데이터는 mock 데이터**를 사용한다.
- 단, 화면은 처음부터 **axios로 서버와 통신하는 형태**로 작성한다. 나중에 실제 서버가 생기면 `baseURL`과 mock adapter만 걷어내면 그대로 동작해야 한다.

## 2. 기술 구성
| 구분 | 내용 |
| --- | --- |
| 빌드/언어 | Vite + React (JavaScript), Tailwind CSS, oxlint, StrictMode 제거 |
| 개발 서버 | 포트 3000, 자동 브라우저 실행 |
| 통신 | axios (`/api` 기준 REST 형태) |
| 라우팅 | react-router-dom |
| 상태(로그인 정보) | zustand (`src/stores`) |
| 폴더 | `pages`(화면) / `comp`(컴포넌트) / `service`(API·mock) / `utils` / `stores` |

## 3. Mock 서버 방식
- axios 인스턴스(`api`)에 **custom adapter**를 연결해 실제 네트워크 없이 요청을 가로채 응답한다.
- 요청 URL/메서드/파라미터/바디/헤더(`Authorization`)를 서버처럼 해석하고, HTTP 상태코드(200/201/400/401/403/404/409)와 에러 메시지를 돌려준다.
- 응답 지연(약 300ms)을 넣어 비동기 통신처럼 보이게 한다.
- mock 데이터는 `localStorage`에 저장해 새로고침해도 유지된다.
- 로그인 성공 시 토큰을 발급하고, 이후 요청에 인터셉터가 `Authorization: Bearer 토큰`을 붙인다. 응답이 401이면 로그아웃 처리 후 로그인 화면으로 이동한다.
- 비밀번호는 응답에 포함하지 않는다.

## 4. 사용자 권한
| 권한 | 코드 | 설명 |
| --- | --- | --- |
| 운영자 | `ADMIN` | 회원 등록/수정/삭제 가능, 모든 게시글 수정/삭제 가능 |
| 사용자 | `USER` | 회원 **목록 조회만** 가능, 게시글은 등록 가능 / **본인 글만** 수정·삭제 (타인 글은 보기만) |
| 비로그인 | - | 게시글 **목록/상세 조회만** 가능. 등록/수정/삭제/회원정보는 로그인 필요 |

## 5. 기능
### 5.1 로그인
- 아이디/비밀번호 입력 → `POST /api/auth/login`
- 실패 시 오류 메시지 표시, 성공 시 게시판으로 이동
- **첫 화면은 게시판 목록**이며 로그인하지 않아도 노출된다 (`/` 및 알 수 없는 경로 → `/posts`)
- 비로그인 상태에서 게시글 등록/수정/삭제, 회원정보 화면에 접근하면 로그인 화면으로 이동하고, 로그인 후 원래 가려던 화면으로 돌아온다
- 회원정보 화면(`/members`)은 **로그인해야만** 볼 수 있다 (비로그인 접근 시 로그인 화면으로 이동)
- 로그아웃 버튼 제공

### 5.2 상단 메뉴
- 좌측: 서비스명, **게시판** 메뉴 (누구나 노출)
- **비로그인**: 우측 끝에 **로그인 버튼** 노출
- **로그인**: 우측 끝에 **회원 아이콘 + 이름** 노출
  - 아이콘 또는 이름을 클릭하면 **드롭다운**이 열린다: 권한(운영자/사용자) 표시, **회원정보**, **로그아웃**
  - 회원정보 → `/members` 이동, 로그아웃 → 로그아웃 후 게시판 목록으로 이동
  - 드롭다운 바깥을 클릭하면 닫힌다
- 회원정보는 상단 메뉴가 아니라 이 드롭다운으로만 진입한다

### 5.3 게시판
- 목록: 번호, 제목, 글쓴이, 조회수, 등록일 (최신순)
- 상세: 제목, 내용, 글쓴이, 조회수, 등록일, 수정일 (상세 진입 시 조회수 +1)
- 등록 / 수정 / 삭제 (삭제는 확인창)
- 글쓴이는 로그인한 회원으로 자동 지정
- 목록/상세는 누구나 조회 가능, 등록/수정/삭제는 로그인 필요
- 사용자(USER)는 본인 글만 수정/삭제 가능 (타인 글에는 수정/삭제 버튼 미노출, 서버도 403). 운영자는 모든 글 수정/삭제 가능

### 5.4 회원정보
- 목록: 아이디, 이름, 권한, 등록일 (모든 로그인 회원 조회 가능)
- 등록/수정/삭제: **운영자만** (사용자에게는 버튼/폼 미노출, 서버도 403 응답)
- 등록 시 권한(운영자/사용자) 선택
- 수정 시 비밀번호를 비우면 기존 비밀번호 유지
- 아이디 중복 불가(409), 본인 계정은 삭제 불가

## 6. 데이터 모델
**회원 member**: `id`, `username`, `password`, `name`, `role`(ADMIN/USER), `createdAt`

**게시글 post**: `id`, `title`, `content`, `authorId`(응답 시 `authorName` 포함), `views`, `createdAt`, `updatedAt`

## 7. API 명세
| 메서드 | URL | 설명 | 권한 |
| --- | --- | --- | --- |
| POST | /api/auth/login | 로그인 | 공개 |
| GET | /api/posts | 게시글 목록 | 공개 |
| GET | /api/posts/:id | 게시글 상세(조회수 +1, `increase=false`면 제외) | 공개 |
| POST | /api/posts | 게시글 등록 | 로그인 |
| PUT | /api/posts/:id | 게시글 수정 | 본인/운영자 |
| DELETE | /api/posts/:id | 게시글 삭제 | 본인/운영자 |
| GET | /api/members | 회원 목록 | 로그인 |
| POST | /api/members | 회원 등록 | 운영자 |
| PUT | /api/members/:id | 회원 수정 | 운영자 |
| DELETE | /api/members/:id | 회원 삭제 | 운영자 |

## 8. 화면 / 라우트
| 경로 | 화면 |
| --- | --- |
| / | 게시글 목록으로 이동 (첫 화면) |
| /login | 로그인 |
| /posts | 게시글 목록 (공개) |
| /posts/new | 게시글 등록 (로그인) |
| /posts/:id | 게시글 상세 (공개) |
| /posts/:id/edit | 게시글 수정 (로그인) |
| /members | 회원 목록 + 등록/수정/삭제 (로그인, 수정은 운영자) |

## 9. 초기 mock 데이터

- 사용자: `user` / `user1234`
- 샘플 게시글 5건

## 10. 기획 시 가정한 사항 (변경 필요 시 알려주세요)
- 운영자는 모든 게시글 수정/삭제 가능(사용자는 본인 글만)
- 게시글 목록 페이징/검색은 이번 범위에서 제외
- 회원 가입 화면은 없음(회원 등록은 운영자가 회원정보 메뉴에서 수행)
